Item Stock Checker is a console-based C++ project that simulates a basic inventory management system.

Features:
• Create a product directory
• Add products with initial stock
• Restock existing products
• Check product availability
• Display all products with their stock
• Menu-driven interface using STL map

Technologies Used:
- C++
- STL map
- Loops
- Switch-case
- Console I/O
  

This project was built to strengthen my understanding of C++ fundamentals and STL containers before moving on to Data Structures and Algorithms.
