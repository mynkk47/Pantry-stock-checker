\# Item Stock Checker



\## Features

\- Create product directory

\- Restock existing products

\- Check product availability

\- Display all products with stock

\- Exit menu

\- Menu reuse after completing tasks

\## Version History



\### v1.0

\- Initial release

\- Create product directory
